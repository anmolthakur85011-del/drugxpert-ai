Welcome to DrugXpert AI

DrugXpert AI is designed to support rational drug formulation development using computational screening, molecular descriptors, machine learning and solvent compatibility analysis.

🔬 Three Core Modules

🧪 HSP Compatibility

Hansen Solubility Parameter based screening of drug–excipient compatibility using δD, δP, δH and Hansen distance (Ra).

🤖 AI/ML Solubility

Molecular descriptor-based prediction of LogS and solubility for drug–excipient systems using machine learning models.

🧴 Solvent Lookup

Computational lookup and ranking of suitable solvents for selected polymers and excipients.

🔗 Integrated Screening

Drug → Excipient → HSP Compatibility → Molecular Descriptor Analysis → AI/ML Solubility Prediction → Solvent Selection → Final Recommendation
